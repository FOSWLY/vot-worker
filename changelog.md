# 1.0.18

Главное изменение релиза устранение ~4-кратного оверхеда по трафику при передаче protobuf в виде JSON. Добиться этого получилось перейдя на прямую передачу protobuf (`application/x-protobuf`) и установку заголовков из единого заголовка запроса `X-VOT-Headers` вместо передачи тела+заголовков в виде JSON (`{body, headers}`)

> [!NOTE]
> Чтобы не возникло проблем при использовании старых клиентов, была сохранена полная обратная совместимость по `content-type`. Все новые клиенты должны использовать `content-type: application/x-protobuf` и заголовок `X-VOT-Headers`. Старая логика будет поддерживаться некоторое время, но в будущем может быть удалена

Еще одним не менее важным изменением является унификация поведения всех трех реализаций воркера по обработке ошибок и валидации запросов. Теперь все три реализации возвращают одинаковые коды ошибок и заголовки при одинаковых ошибках запроса

## Axum

- [унификация] Теперь принимается `application/json` с дополнительными параметрами, например `charset=utf-8`
- [унификация] Для неизвестных маршрутов добавляется заголовок `X-Yandex-Status: error-path`
- [унификация] Ошибки формы JSON-конверта возвращают `X-Yandex-Status: error-request`
- Ответы upstream теперь стримятся без полной буферизации в памяти
- Добавлены тесты обработки ошибок запроса, бинарного пути и форм конверта

## Cloudflare

- [!] Переведен на Module Worker
- [унификация] Добавлена поддержка метода HEAD для проксирования audio и subtitles
- [унификация] Пустой query при проксировании S3 теперь отклоняется
- [унификация] Некорректное расширение audio теперь возвращает `X-Yandex-Status: error-content`
- [унификация] Некорректный JSON-конверт отклоняется локально с `error-request` (мусор больше не уходит в upstream)
- [унификация] `fail-audio-js` принудительно отправляет `Content-Type: application/json` (заголовки конверта больше не могут его переопределить)

## Elysia

- [!] Миграция на новую систему конфигов

  Теперь, все настройки могут быть установлены из переменных окружения. Названия существующих переменных окружения не были изменены, все новые переменные окружения представлены ниже:

  ```bash
  SERVICE_HOSTNAME=...
  USER_AGENT=...
  LOG_PATH=...
  CORS_ACCESS-CONTROL-ALLOW-ORIGIN=...
  CORS_ACCESS-CONTROL-ALLOW-HEADERS=...
  CORS_ACCESS-CONTROL-ALLOW-METHODS=...
  CORS_ACCESS-CONTROL-MAX-AGE=...
  S3_URLS_AUDIO=...
  S3_URLS_SUBS=...
  YANDEX_API_URL=...
  ```

- [унификация] Для неизвестных маршрутов добавляется заголовок `X-Yandex-Status: error-path`
- [унификация] Исправлен заголовок X-Yandex-Status при ошибках валидации запроса (ранее всегда возвращался error-content вместо error-request)
- [унификация] Ошибки формы JSON-конверта возвращают `error-request` (неизвестный Content-Type — `error-content`, malformed JSON — `400 Bad Request`)
- Удалена устаревшая буферизация ответов S3, Range-ответы теперь стримятся напрямую (исправлено в Bun 1.1.9+)
- Миграция на новую систему регистрации внутренних моделей
- Миграция workspace с eslint на современную версию oxlint
- Обновлены зависимости

## Shared

- [!] Добавлена поддержка проксирования с помощью protobuf + заголовка `X-VOT-Headers` (Base64(JSON))
- Добавлена поддержка установка заголовка ответа `X-VOT-SERVER-ID` для идентификации воркера, который обработал запрос
- [унификация] Заголовок `Range` теперь проксируется для audio и subtitles
- [унификация] Сетевые ошибки upstream возвращают `X-Yandex-Status: error-internal`
- [унификация] Несовпадение HTTP-метода возвращает `X-Yandex-Status: error-path`
- [унификация] Некорректный внешний JSON возвращается с кодом `400 Bad Request`
- [унификация] `fail-audio-js` принимает строковое JSON-тело, передает его без повторной сериализации и принудительно использует `application/json`
- [унификация] Очистка заголовков ответа использует только `upgrade` и `transfer-encoding` как hop-by-hop заголовки
- Адрес Yandex API теперь задается через переменную окружения `YANDEX_API_URL` (по умолчанию `https://api.browser.yandex.ru`)
- Обновлен стандартный User Agent
